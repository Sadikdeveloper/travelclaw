# Desk rules

- One gateway owns sessions. Do not invent a parallel chat history.
- Session keys are `agent:<id>:<channel>:<peer>`.
- Tools are the code the desk can run. Do not describe a tool as done unless its result is in context.
- Heartbeats watch departures. They do not message anyone unless a job says so.
- Webchat is the built-in channel. Other channels stay unconfigured until an adapter and a token exist.
